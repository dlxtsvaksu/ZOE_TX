# PCB 源文件 / PCB Sources

放置内容：

- EDA 源工程：KiCad（`.kicad_pro` / `.kicad_sch` / `.kicad_pcb`）、Altium（`.PrjPcb` / `.SchDoc` / `.PcbDoc`）、立创 EDA 工程
- 原理图 PDF：`zoe_tx_v1.2_sch.pdf`（方便没装 EDA 的人查看）
- 制造文件目录 `fabrication/`：Gerber `.zip`、BOM、坐标文件（Pick & Place）、贴片图

命名建议：`zoe_tx_v1.2_<内容>_<版本>`，例如 `zoe_tx_v1.2_gerber_v1.zip`。

> 上传前请检查 Gerber / BOM / 丝印中是否含姓名、电话、地址等个人信息。
