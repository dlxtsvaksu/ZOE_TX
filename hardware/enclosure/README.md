# 外壳 / 结构件 / Enclosure

放置内容：

- 中性格式：`zoe_tx_v1.2_case.step`（任何人可打开，优先提供）
- 3D 打印：`zoe_tx_v1.2_case.stl` 或 `.3mf`
- CAD 源工程：Fusion 360（`.f3d`）、SolidWorks（`.SLDPRT` / `.SLDASM`）、FreeCAD（`.FCStd`）

命名建议：`zoe_tx_v1.2_<零件>_<版本>.step`，例如 `zoe_tx_v1.2_case_top_v1.step`。

> STL 文件通常几 MB 到几十 MB，注意单文件 100 MB 的 Git 限制；更大的模型建议作为 Release 附件。
